# 音浪 YINLANG

通过 AI Agent 协作开发的音乐人观察看板，将近期作品、音乐平台表现、听众画像分析与演出活动整合在一个网页中，为音乐推广和听众增长策略提供参考。

## 核心功能

- 艺人管理：搜索、添加和删除关注的艺人。
- 近期作品：查看已收录的新歌、专辑及音乐平台链接。
- 音乐指标：展示可核对的音乐表现数据及来源。
- 听众分析：分析潜在听众兴趣与音乐发现路径。
- 演出活动：区分已官宣、待官宣和已结束的活动。

## 我的贡献

主导产品需求、信息架构与体验迭代，使用 AI Agent 协助完成资料检索、网页开发和功能验证，持续优化内容选择、数据质量与交互体验。
