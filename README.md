- 榜位注明榜单日期和读取时间，不等同播放量或听众数。新歌发现、网易云播放/收藏及平台听众画像尚未实现自动采集。下方较早版本的“仅微博自动采集”描述已被本节替代。

- 验证音乐解析、身份匹配、异常页面拒绝入库、音乐指标筛选、活动状态、删除持久化和浏览器显示。已通过接口实际读取音乐页面，页面更新时间与读取时间分别保留。

公开网页优先、截图补充。不需要用户登录、密码、API 密钥或付费数据服务。

## 启动

`python3 server.py`，打开 http://127.0.0.1:8766。

直接打开 index.html 也能看最近保存的资料，但自动更新需要上面的本地服务。不要用旧的静态预览端口测试更新功能。

## 已实现并实际核对

- 从无需登录的新浪公开微博主页读取本人姓名、头像、粉丝数、关注数、微博数量。
- 已核对王力宏、Chace、欧阳娜娜、单依纯、丁世光的公开主页，记录于 public_sources.json。
- 周杰伦暂不绑定来源，不将厂牌/工作室数据替代本人指标。
- 打开或切换艺人时检查资料，页面可见时每 15 分钟检查当前艺人；后端缓存 15 分钟。
- 提供「更新公开资料」按钮；读取失败保留最近成功记录，不改变原读取时间。
- 新增艺人可提供本人微博数字 ID 主页或新浪 media 主页；请求固定为新浪公开域名，核对页面姓名后才接受。
- public-data.json/public-data.js 保留最近成功读取的真实数据，便于静态预览。
- 头像是来源页当时使用的头像，不能确定照片的拍摄日期；签名图片可能到期，更新资料后会重新取得 URL。

## 数据边界

读取时间不等于平台更新时间。新浪的公开微博展示可能存在同步延迟；不标成秒级实时数据。搜索引擎缓存不会冒充本次直接读取结果。粉丝「31.2万」保留原始精度，不当作精确 312000 绘图。

目前自动读取源只有新浪公开微博页。网易云、QQ音乐及其他平台尚未实现自动采集；不能把本次遇到的登录页或网络限制理解为所有公开资料都必须登录。今后可继续加入实际可访问的公开页面。遇到登录墙、访问拒绝或页面结构变化会停止提取，不使用私人 Cookie 或绕过登录。
